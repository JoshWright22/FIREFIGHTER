# firefighter for VS Code, Cursor and Windsurf

Shows [firefighter](https://github.com/JoshWright22/firefighter) in the status bar: what the human is
doing, how many agent jobs are running and waiting, and the GPU market (price, busy odds). Hover for
the queue; click for the full status. Needs the `firefighter` binary on your PATH (or set
`firefighter.path`).
